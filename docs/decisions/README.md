# Architecture decision records

An architecture decision record, or ADR, explains an important choice and keeps the reasoning with the code it affects.

Use four-digit numbers in order: `0001-title.md`, `0002-title.md`, and so on. Keep old decisions when they are replaced. Mark them as superseded and link to the newer ADR.

Each ADR must include its status, context, alternatives, comparison criteria, decision, consequences, evidence, limits, and conditions for revisiting the choice.
